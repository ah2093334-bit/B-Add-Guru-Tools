یہ ZIP PUBLIC WEBSITE کے لیے ہے۔ اسے GitHub Public Repository میں upload کرنا ہے۔

حصہ 1 — GitHub Public Website
1) ZIP extract کریں۔
2) اپنی GitHub repository: b-add-guru-tools کھولیں۔
3) Add file -> Upload files پر click کریں۔
4) اس ZIP کے اندر موجود تمام files/folders upload کریں۔
5) Commit changes دبائیں۔
6) Settings -> Pages کھولیں۔
7) Source = Deploy from a branch۔
8) Branch = main اور folder = /(root)۔
9) Save۔
10) چند منٹ بعد GitHub Pages URL کھولیں۔

حصہ 2 — Supabase بنانا
1) supabase.com پر account بنائیں۔
2) New Project دبائیں۔
3) Project name: b-add-guru-tools۔
4) strong database password رکھیں اور محفوظ کریں۔
5) project بننے کے بعد Project Settings -> API کھولیں۔
6) Project URL اور anon/publishable key copy کریں۔
7) public website میں assets/js/config.js کھولیں۔
8) PASTE_YOUR_SUPABASE_URL کی جگہ Project URL لگائیں۔
9) PASTE_YOUR_SUPABASE_ANON_KEY کی جگہ anon/publishable key لگائیں۔
10) Gemini/Veo/payment secret یہاں مت لگائیں۔
11) updated config.js GitHub میں دوبارہ upload/commit کریں۔

حصہ 3 — Database
1) Supabase -> SQL Editor۔
2) New query۔
3) public ZIP کے supabase/schema.sql کا پورا متن paste کریں۔
4) Run دبائیں۔
5) اس سے profiles, subscriptions, tool_entitlements, payment/usage tables بنیں گی۔

حصہ 4 — Email verification
1) Authentication -> Providers -> Email۔
2) Email/password sign-in enable رکھیں۔

User email verify کرنے کے بعد QR code scan کرے گا۔

یہ LocalAppData میں install ہوگا اور Windows startup پر background میں چل سکتا ہے۔
